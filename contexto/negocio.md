# Negócio

Preencha com dados reais. O que estiver vazio, os squads perguntam antes de
usar.

- O que vende?
- Para quem vende?
- Como entrega (formato: curso, mentoria, consultoria, produto físico...)?
- Ticket médio?
- Canais de venda e divulgação?
- Momento atual do negócio (faturamento, etapa, principal gargalo)?
- Meta para os próximos 90 dias?
